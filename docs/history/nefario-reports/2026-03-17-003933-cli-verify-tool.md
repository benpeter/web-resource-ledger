## Summary

Built `@wrl/verify`, a standalone CLI npm package at `packages/verify/` that provides independent, offline-capable cryptographic verification of WRL WACZ captures. The tool adds full CMS/PKCS#7 certificate chain validation for RFC 3161 timestamps -- a capability the Worker explicitly defers. 5-check verification pipeline, three key trust levels, human-readable and JSON output, exit codes for CI integration. 136 tests pass.

## Original Prompt

Build a standalone CLI npm package (`@wrl/verify`) for full cryptographic verification of WRL captures including RFC 3161 CMS/PKCS#7 signature verification against TSA certificate chain. npx-runnable, zero-install, local files and remote URLs, human-readable and JSON output, exit code 0/1/2.

## Key Design Decisions

1. **PKIjs for CMS chain validation** -- only viable library (node-forge broken, @peculiar/x509 lacks CMS, hand-rolling too risky)
2. **Vendor modules** -- no monorepo workspace, copy 4 modules from Worker with Node.js adaptations
3. **5 checks** -- split timestamp into imprint (hash match) and chain (CMS signature + cert chain)
4. **Origin-verified key resolution** -- remote auto-resolve, local requires explicit source
5. **node:test** -- zero dependencies, matches CLI's lightweight ethos
6. **No --verbose** -- default shows everything, --json for power users
