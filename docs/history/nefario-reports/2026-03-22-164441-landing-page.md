## Summary

Static HTML/CSS landing page for webresourceledger.com. Zero JavaScript, zero web fonts, zero third-party resources. Hero, how-it-works (3-step flow), use cases (4-card grid), pricing (3-tier cards), and footer sections. Full SEO metadata (2 JSON-LD blocks, Open Graph, Twitter Card, canonical URL, robots.txt, sitemap.xml). WCAG AA accessibility with skip link, heading hierarchy, aria-labelledby, dark-background focus indicators, and touch target sizing. Deployed via Cloudflare Workers Static Assets with GitHub Actions CI that copies design-system.css and SVG assets into place. Mobile-first responsive with breakpoints at 768px and 1024px.

## Original Prompt

Build a static landing page for WRL at webresourceledger.com. Plain HTML/CSS, no JS frameworks. Uses the WRL brand design system. Deployed on Cloudflare Workers Static Assets. Sections: hero, how-it-works, use cases, pricing, footer. Lighthouse perf >= 95, a11y >= 90. Responsive. Deploy via CI on push to main.

## Key Design Decisions

1. **Standalone deployment over 11ty integration** -- Landing page is on a different domain (webresourceledger.com vs docs.webresourceledger.com). Plain HTML needs no build system. Decoupled deployment prevents landing from being coupled to docs infrastructure. iac-minion recommended standalone; ux-design-minion recommended 11ty; synthesis chose standalone per KISS.

2. **CSS architecture: landing.css extends design-system.css** -- Landing-specific tokens (--text-hero, --space-16/20/24, btn--lg, btn--inverse) defined in landing.css under :root. Design system stays minimal and generic. No modifications to design-system.css.

3. **Pricing JSON-LD without Offers** -- seo-minion recommended omitting Offers array from SoftwareApplication structured data since pricing tiers are illustrative placeholders. Prevents misleading search engines and avoids maintenance burden when real pricing ships.

4. **Zero JavaScript enables script-src 'none'** -- No JS at all (JSON-LD is type=application/ld+json, not executable). Smooth scrolling via CSS scroll-behavior. Nav links wrap gracefully without hamburger. No animations needed. Strongest possible CSP.

5. **OG image deferred** -- A poor OG image is worse than none. Twitter/Facebook use default card rendering. OG image tracked as follow-up backlog item.
