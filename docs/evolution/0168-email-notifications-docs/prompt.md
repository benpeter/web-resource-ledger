# Prompt

Same session as phases 0133 to 0167, not from the backlog: a sweep of the docs
against the code (after #415 fixed the capture time and the batch limits) found
that the docs never mention the emails WRL sends. An account gets up to six
kinds of notification email, all turned on by default, plus sign-in and
verification emails, and the dashboard has a Notifications page to change them,
but no docs page says which emails exist, when they go out, or how to stop them.
