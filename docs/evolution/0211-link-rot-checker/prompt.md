# Prompt

Backlog #56 (public issue #251): a free Link Rot Checker on
webresourceledger.com as a lead magnet. Paste or upload up to 100 URLs, see
which work, redirect, are gone or time out, with the HTTP code, the redirect
chain and the response time, a summary, a link to share the run and a
contextual WRL call to action. No account, no email gate, vanilla JS,
Cloudflare only. Out of scope: accounts, scheduled re-checks, a public API,
crawling and soft-404 detection. Ben dropped the backlog trigger on
2026-11-25 and approved building it.
