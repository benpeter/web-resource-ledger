# 0004: Backlog Extraction

## Task

Go through all existing documentation in `docs/evolution/` and
`docs/history/` from previous phases. Extract everything that was explicitly
deferred, flagged as post-MVP, or noted as a future consideration.

Categorize each item into one of:
1. **Must-have** -- explicitly committed to, just not yet
2. **Should-have** -- strong consensus it's needed but no hard commitment
3. **Consider** -- mentioned as a possibility, may or may not be needed

Propose a documentation format for the backlog. Evaluate alternatives to
GitHub issues. Deliver the backlog document, this evolution log entry, and a
recommendation for backlog maintenance conventions.

- No nefario orchestration -- solo research-and-document task
- Don't create GitHub issues yet
- Don't implement any backlog items -- just capture them
