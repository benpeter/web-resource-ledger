**Outcome**: Every WRL capture can produce a downloadable FRE 902(13) certification document - a structured, human-readable PDF that attests to the automated capture process, integrity hashes, and timestamp evidence. This document is designed to satisfy Federal Rules of Evidence 902(13) self-authentication requirements, eliminating the need for live testimony to authenticate web capture evidence in US court proceedings.

**Success criteria**:
- API endpoint: `GET /v1/captures/{id}/certificate` returns a PDF certification document
- Web UI: "Download Certificate" button on capture detail view
- Document includes:
  - Capture URL, date/time (UTC), and captureId
  - SHA-256 hash of the WACZ bundle
  - Ed25519 signature and public key identifier
  - RFC 3161 timestamp details (TSA identity, timestamp value)
  - eIDAS qualified timestamp details (if enabled on account)
  - Description of the automated capture process (no human intervention, server-side browser, SSRF protection)
  - Statement that the record is a true and accurate copy produced by an automated system
  - WRL operator identity and contact
- Document is deterministic: same captureId always produces the same PDF (no random elements)
- Document itself is signed (Ed25519 signature embedded or detached)
- PDF generation uses a lightweight library (no heavy dependencies - e.g., pdf-lib or similar)
- Works for any existing capture (generates on demand from stored capture metadata)

**Scope**:
- In: PDF generation endpoint, certification document template, Ed25519 signing of the document, web UI download button, API documentation
- Out: Notarization integration, attorney review of language (disclaimer included), batch certificate generation, customizable templates per tenant

**Constraints**:
- Depends on R30 (D1 for capture metadata)
- Depends on R17 (web UI for download button)
- PDF must be self-contained (no external resource loading)
- Legal disclaimer: "This document is generated by an automated system. It is not a legal opinion. Consult an attorney for jurisdiction-specific evidentiary requirements."
- Language must be precise but accessible - written for a paralegal or attorney who understands evidence rules but not cryptography
- Budget: $40 - template design + PDF generation + endpoint
